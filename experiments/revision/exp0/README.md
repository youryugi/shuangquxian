# 实验 0：重新构思 band attention——以曲线为单位的检测器

**状态**：2026-11-25 开始；第 1 轮（4 个 arm × 5 折 × 10 seeds）2026-11-26 完成。

**问题**：抛开现有做法，单纯从 band 本身出发，band attention 应该怎么设计才能发挥价值、发挥什么价值？

## 答案（截至第 1 轮）

1. **以曲线为单位检测（顶点 + slope + 半宽，框由曲线算）本身就比框检测器好**：不聚合的 `curve_local` 对 exp1 baseline +0.053 F1（9/1），AP50 +0.066；完整的 `curve_hough` 对 baseline +0.047（8/2），F1@0.7 +0.059（10/0），单翼目标 recall +0.244、weak +0.103。这部分提升主要来自"以曲线为单位"，不来自沿曲线聚合。
2. **沿曲线聚合（band attention 作为聚合核）没有提高框 F1**：hough 对 local −0.006（4/6，n.s.）；weak recall +0.010（n.s.）。"弱目标靠沿曲线累积"在这一轮**没有得到支持**。
3. **但它让排序和速度估计更好**：hough 对 local AP50 +0.023 [+0.003, +0.045]；slope 误差（|log 比| 中位数）0.112 → 0.083（10/10 个 seed 都更低，约 −26%）；顶点误差略差（2.8 → 3.0 px）。
4. **是形状在起作用，不是区域**：同样多的采样点散布在外接框里（`boxgrid`）比只看顶点还差（−0.017，2/8）；沿曲线比散布 F1 +0.011（n.s.）、AP50 +0.035、grouped recall +0.057（9/1）、slope 误差 0.129 → 0.083（10/10）。
5. **band 标注比框标注多给了东西**：同一网络只用框反推的伪曲线监督（`boxpseudo`）比用 HBAT 标注低 0.030 F1（7/3，CI [+0.004, +0.057]），AP50 低 0.050；差在单翼（+0.092）、畸变（+0.059）、宽目标（+0.083），顶点误差 3.3 → 3.0 px、slope 误差 0.099 → 0.083。
6. **还没到 band + fit**：所有曲线 arm 都比 exp1 的 band + fit（0.585）低 0.06（0/10）。

结果文件：`results/r1.md`（主表和配对）、`results/r1.json`（每个 seed）、`results/r1_strata.md`（分层 recall）。

## 术语表

| 术语 | 含义 |
|---|---|
| **curve / 曲线** | 一个目标的双曲线中心线，HBAT 模型：`y_c(x) = y_v + a(√(1 + ((x − x_v)/b)²) − 1)`，`a = max(1, |y_v|)`，`b = a / slope` |
| **apex / 顶点** | (x_v, y_v)，可以在图外（单翼目标） |
| **slope** | 渐近线斜率 a/b = 2/v，对应波速 |
| **half-width w** | 曲线水平半宽 = span / 2；框的左右边 = x_v ± w |
| **hypothesis / 假设** | 一个候选 (顶点格子, slope 档位)；每个假设对应图上一条确定的曲线 |
| **hyperbola aggregation layer / 双曲线聚合层** | 对每个假设沿它的曲线采样特征并加起来的层（可学习的 migration / Hough） |
| **arc gate / 沿弧门控** | 曲线上每个采样点的权重 ∈ (0, 1)，表示"这一段有没有信号"；用标注的 span 监督 |

## 1. 出发点

### 1.1 前提

band 标注只在训练时有。推理时 band attention 不能带来新信息，价值只能来自：
1. **训练信号**：band 作为额外监督，改变学到的特征（privileged information，Vapnik & Vashist 2009；辅助任务，Caruana 1997）；
2. **计算结构**：把"目标是一条双曲线"写进运算，让网络做出它自己学不到的计算。

而且 band 能贡献的只是**它比框多出来的信息**：框里哪些像素是回波、曲线的形状（被截断 / 单翼 / 畸变时框推不出来）、重叠目标的归属（框在面积上重叠，曲线只在点上相交）、物理量（slope = 2/v，深度 = v·t₀/2）。

### 1.2 attention 的五种角色

| 角色 | 做什么 | 依据 | 价值 | 用到 band 的什么 |
|---|---|---|---|---|
| ① 门控 | 特征乘权重图 | 特征选择 | 少一些杂波误检 | 只有覆盖区域 |
| ② 聚合核 | 沿假设的曲线把证据加起来 | 匹配滤波；migration、Hough 变换 | 弱目标：N 点相干叠加，信噪比约 ×√N | 形状 |
| ③ 实例关联 | 像素归给解释它的那条曲线 | 曲线只在点上相交；PAF（Cao 2017）、Slot Attention（Locatello 2020） | 密集目标分得开 | 形状 + 归属 |
| ④ 几何解码 | 读出曲线参数，框由曲线算 | 双曲线方程 | 深度 / 速度；框的外延按曲线推 | 参数 |
| ⑤ 训练约束 | 要求网络基于正确的区域判断 | Ross 2017、GAIN（Li 2018） | 少数据、跨场景更稳 | 区域 + 形状 |

- ① 只区分里外，覆盖区域相近的 mask（椭圆、框）效果会接近，是价值最小的用法。
- ② 依据最硬：已知形状的信号在噪声里的最优检测统计量就是沿形状加权积分。卷积网络的有效感受野远小于理论感受野（Luo et al., NeurIPS 2016），自己很难学出跨几十像素的弯曲积分核。直线检测里的先例：Deep Hough Transform（Zhao et al., ECCV 2020）。
- ⑤ 的前提：attention 必须在因果路径上，不能被绕过（Jain & Wallace 2019）。

### 1.3 设计原则

1. 用 band 的形状，不只用区域。
2. 把"曲线在哪"（几何，参数给出，可延伸到看不见的地方）和"哪里有信号"（沿弧的权重，翼尖物理上就弱：扩散、天线方向图、衰减）分开。均匀 band 监督要求网络在没信号的地方输出高 attention，是矛盾监督。
3. 以实例为单位，不是全图一张并集。
4. 参数化 + 允许小幅偏离。
5. 利用物理量的共享：同一测线的速度相近（ds2 同图 slope 的平均 log 偏差 0.074，随机分组 0.151；可能部分来自标注习惯）。

**聚合必须在提候选那一步做**：候选如果从局部热图里挑，弱目标第一步就丢了。

## 2. 网络

```
图像 224 → backbone（与 exp1 相同的三层下采样 + bottleneck）
  → bottleneck 上采样回 56×56 与 f3 拼接 → 1×1 降到 16 通道：证据特征 E
  ① 双曲线聚合层（dense）
     假设 = 28×28 个顶点格子（步长 8）× 8 档 slope（1.1–5.2 对数等距）
     每个假设沿自己的曲线取 M = 27 个水平位置（|dx| ≤ 100 px）× 横向 3 个偏移（−4 / 0 / +4 px），双线性采样 E
     每点：MLP(特征 + 是否在图内 + 位置编码 + slope 档位编码) → u_m
     沿弧门控 a_m = sigmoid(w·u_m + β_{k,m})   ← band attention 在这里
     左翼、右翼分别按 a_m 加权平均，加上顶点处的 u_0、两翼平均门控 → MLP
     → 每个假设：分数、顶点偏移、log slope 残差、log 半宽、log 厚度
  输出：取峰值 → 曲线参数 → 框由曲线算
     x1, x2 = x_v ∓ w；y1 = y_v − th/2；y2 = y_c(x_v + w) + th/2；裁到图内（与 HBAT 由 band 推框的公式相同）
```

- 采样位置只由假设决定、与图像无关，所以采样写成固定矩阵的乘法（水平平移矩阵 × 逐行重映射矩阵），前向反向都是确定性的。
- 监督全部来自 HBAT 标注：顶点 → 3 维热图（空间 + slope 档位）；slope → 档位 + 残差；span → 半宽和沿弧门控目标（|dx| ≤ span/2 为 1）；thickness → 厚度。6 个没有 band 参数的目标用框反推的伪曲线。

## 3. 要检验的假设和对照（第 1 步）

都在同一网络、同一配对初始化（backbone 和 head 逐参数相同）、同一数据顺序下，5 折 × 10 seeds：

| arm | 和完整方法的差别 | 回答的问题 |
|---|---|---|
| `curve_hough` | 完整方法 | — |
| `curve_local` | 每个假设只看顶点处一个位置（M = 1），没有沿曲线聚合 | 沿曲线聚合有没有用（"同一检测器不加 band attention"） |
| `curve_boxgrid` | 采样点数相同，但散布在曲线外接框的面积里，不沿曲线 | 是形状在起作用，还是只是看的区域更大 |
| `curve_hough_boxpseudo` | 结构相同，所有监督（顶点、slope、半宽、门控）换成只由框反推的伪曲线 | band 标注比框标注多给了什么（对应 box-mask 对照） |

评估：主指标仍是框的 F1@IoU0.5（框由曲线算，`shared/evaluate.py`，验证集选阈值），可以直接和 exp1 的 baseline、YOLO 等比；另报曲线指标（命中目标的顶点误差、slope 误差）和 weak / grouped 分层。

## Round 记录

### Round 0：实现检查（2026-11-25）

- 曲线参数 → 框与 GT 框一致：val / test 最小 IoU 0.999 / 1.000；训练集 151 条 HBAT 曲线 + 6 个没有 band 参数的目标用伪曲线（最小 IoU 0.871，来自厚度截断）。
- 采样几何：在 GT 假设上，`hough` 的采样点在 span 内落在 band 上的比例 0.83（span 外 0.06）；`boxgrid` 0.22。
- 配对初始化：各 arm 的 backbone 和 head 指纹相同；backbone 与 exp1 `hbatbox_flipfix_none` 的同 seed 初始化逐参数相同（第一层卷积和 −4.4034）。数据顺序和翻转与它逐样本相同（`--workers 1`）。

### Round 1a：选顶点热图 sigma（2026-11-25）

**为什么**：sigma 是新网络唯一没有现成取值的超参。按协议在"不加 band attention"的 arm（`curve_local`）的合并验证集上选，所有 arm 共用。

**做了什么**：sigma ∈ {1, 2, 4} 格子 × {local, hough} × 5 折 × seeds 0–2（`pilot_*`，90 个 run）。

**结果**（5 折合并，3 seeds 平均）：

| | val F1 | test F1 | AP50 |
|---|---|---|---|
| local σ1 / σ2 / σ4 | 0.492 / **0.509** / 0.495 | 0.506 / 0.521 / 0.510 | 0.419 / 0.437 / 0.419 |
| hough σ1 / σ2 / σ4 | 0.457 / 0.470 / 0.479 | 0.541 / 0.513 / 0.533 | 0.475 / 0.457 / 0.477 |
| exp1 baseline `hbatbox_flipfix_none`（同 3 seeds） | 0.522 | 0.457 | 0.397 |

**结论**：按规则选 **σ = 2**（local 验证集最高）。只看 3 个 seed：local → hough 在 σ1 / σ4 上 +0.034 / +0.023（3/0），σ2 上 −0.008（1/2）；AP50 三档都是 hough 高（+0.02 到 +0.06）。曲线检测器本身（不聚合）已比 exp1 baseline 高 +0.064（3/0）。验证集只有约 70 个目标，val 和 test 的排序不一致，正式结论看第 1 轮的 10 seeds。

### Round 1：四个 arm 的正式对比（2026-11-26）

**为什么**：分开回答三个问题：沿曲线聚合有没有用（hough vs local）、是形状还是区域（hough vs boxgrid）、band 标注比框多给了什么（hough vs boxpseudo）。

**做了什么**：σ = 2，4 个 arm × 5 折 × 10 seeds = 200 个 run（seeds 0–4 在 IWAC1，5–9 在 IWAC2）。汇总口径同 exp1：每个 seed 5 折验证集合并选阈值、5 折测试集合并（131 张、222 个目标）算 F1，按 seed 配对。exp1 的 run 作参照行（同划分、同 backbone 初始化、同数据顺序和翻转）。曲线误差只在各 arm 自己命中的、有 HBAT 参数的 GT 上算（集合不完全相同）。

**结论**
- 以曲线为单位检测是这一轮最大的收益（对框检测器 +0.05），连带 weak 和单翼目标的 recall 大幅提高；但它和沿曲线聚合无关（local 拿到几乎全部）。
- 沿曲线聚合在框 F1 上无作用，弱目标假设没有得到支持；它的作用在排序（AP50）和 slope 估计（10/10）。
- 和散布在框里的对照比，沿曲线更好（AP50、grouped、slope），区域聚合本身反而有害：形状是关键，但带来的框 F1 差异还不显著。
- band 标注相对框标注的价值在这个网络里成立（+0.030 F1，单翼 / 畸变 / 宽目标、顶点和 slope 误差）。
- 和 band + fit 还差 0.065。

**下一步候选**：① 聚合层目前只在 28×28 顶点格子 × 8 档 slope 上做一次、证据特征只有 16 通道，可以加第二阶段（每个候选沿曲线更密采样、迭代修正参数，README 第 2 节的 ②）；② 门控监督 λ 和横向偏移未调；③ 竞争（③）和同图速度先验（④）还没做；④ 曲线指标和 grouped 的提升值得在论文里单独报。
