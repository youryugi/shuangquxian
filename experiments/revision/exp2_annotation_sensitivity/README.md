# 实验 2：标注敏感性（数据集 2）

**问题**：HBAT 的标注参数（厚度、跨度、顶点、slope）标偏了，或者带着正常的标注误差，band + hyperbola fit 的提升还在吗？回应审稿意见 R1-4（"标注参数变化对最终检测性能的敏感性"）、R2-4（"对条带厚度和跨度的敏感性"），也回应 R1-2（"固定宽度条带"）。

**答案（2026-11-22，5 折合并 × 10 seeds，和实验 1 Round 18 配对）**

1. **厚度在 ×0.5 到 ×1.25 之间结果不变**（0.578–0.579 对标准 0.585，不显著），对 box-mask 最好的后处理仍 +0.037 到 +0.038。
2. **全部目标用同一个厚度（中位数 16.3 px）和逐个标几乎一样**（0.583，−0.002）。HBAT 可以省掉调厚度这一步；在数据集 2 上"固定宽度条带"不损失性能。
3. **跨度是最敏感的参数**：±25% 都掉 −0.047。论文要写清楚跨度标到可见的翼尖。
4. **在实测的标注误差下结论不变**：顶点 2 px、slope ±10%、同一人重复标注的差值，F1 掉 −0.008 到 −0.012（不显著）。仍对 baseline +0.100 到 +0.104（10/10），对 box-mask 最好的后处理 +0.031 到 +0.035。
5. 厚度太细（×0.25）或太粗（×1.5、×2）、误差加倍，都会下降，但 **15 个档位 band + fit 全部赢 baseline**（最差 +0.049，10/10）。太粗时 band 退化成近似框，和 box-mask 对照打平。

还没做：两位标注员之间的一致性（R2-4，要等第二位标注员）。等两人的标注出来后，用两人的实测差值替换下面第 2 档的误差量级。

## 术语

| 术语 | 含义 |
|---|---|
| band + fit | 实验 1 的方法：band 监督的 attention 画出双曲线带，沿预测的带拟合双曲线定框（实验 1 Round 15、18） |
| box-mask 最好的后处理 | box-mask 对照臂（attention 监督换成填实的框）在所有后处理里最好的一个：Voronoi + NMS，F1 0.541 |
| 标准档 | 原始 HBAT 标注训练的 band 臂（实验 1 Round 18 的 `hbatbox_flipfix_abs`），band + fit 0.585 |
| 档位 | 一套扰动后的标注（例如"厚度 ×0.5"），每档单独训练 5 折 × 10 seeds |
| 配对 Δ / 胜/平/负 | 同一 seed（同一初始化、同一数据顺序）下两组的 F1 差，10 个 seed 的均值、bootstrap 95% CI、10 次里赢 / 平 / 输的次数 |

## 设置

- **只换 attention 的监督掩码。** 训练集、验证集的 `masks_band` 换成扰动后的版本，用 HBAT 自己的 `band_mask` 重画（[make_annot_masks.py](make_annot_masks.py)）。检测框（HBAT 派生框）、测试集、baseline、box-mask 对照都和实验 1 Round 18 相同。脚本先自检：不扰动时重画的掩码和 `masks_band` 逐像素相同。
- **扰动按目标定义在整个数据集上**，和折无关，等于"换了一份标注"。随机档每个目标抽一次（种子固定）；同一类的两档共用同一组随机数，只差倍数。
- **档位（共 15 个）**
  - 第 1 档，系统偏差（R2-4 点名）：厚度 ×0.25 / 0.5 / 0.75 / 1.25 / 1.5 / 2（中心线不变，下限 2 px）；统一厚度（全部目标取中位数 16.3 px）；跨度 ×0.75 / 1.25。
  - 第 2 档，随机标注误差：顶点沿随机方向移 2 / 5 px；slope ×(1 ± 10% / 20%)，符号随机；重复标注差值 ×1 / ×2。
- **误差量级的依据**：legacy `augmented_247_hbat` 里，同一标注员对 aug_1 和 aug_6（几何不变的两个增强版本）分别标过 68 个目标。两次之间顶点距离中位数 2.6 px、90% 分位 5.4 px；log slope、log 厚度、log 跨度之差的 std 是 0.09 / 0.21 / 0.19。"重复标注差值"档从这 68 对里整组抽一对差值（随机正负号）加到每个目标上，保留各参数之间的相关。
- 扰动后的训练掩码和原始掩码的像素 IoU 见 [results/mask_stats.md](results/mask_stats.md)。重复标注差值 ×1 只有 0.58，即同一人标两次的 band 本身就只重合六成。叠加图 `results/overlay_<档位>.png`（白 = 原始，红 = 扰动后）。
- **训练和后处理**用实验 1 的管线，协议和 Round 18 相同：
  - 每档训练 band 臂 5 折 × 10 seeds（`hbatbox_flipfix_abs_ann_<档位>`，`--workers 1`，和 Round 18 配对初始化），共 750 个 run；
  - 后处理：band + fit（全参数网格，在合并验证集上选参）和 Voronoi + NMS；
  - 另加"固定 Round 18 参数的 band + fit"（`*_r18_fitbox`，(0.7, 0.1, union, NMS 0.5)），把"训练受影响"和"重新选参补回"分开；
  - 重推理和训练时导出的预测最大差 0。

## 结论

1. **厚度在 ×0.5 到 ×1.25 之间是一个平台**：band + fit 和标准档差 −0.006，都不显著；对 baseline +0.106 到 +0.107、对 box-mask 最好的后处理 +0.037 到 +0.038，都和标准档同一结论。两头下降：太细（×0.25）的掩码画出的 band 只盖住 20% 的中心线，fit 找不到曲线；太粗（×1.5、×2）时 alone 目标的 recall 掉到 0.53–0.54，band 退化成近似框，对 box-mask 最好的后处理不再显著。这就是"厚度合适的双曲线带最好"，厚度 ×∞ 的极限就是 box-mask 对照。
2. **统一厚度和逐个标几乎一样**（0.583 vs 0.585，−0.002，5/5）。厚度不需要逐个调：HBAT 可以固定一个厚度，省掉调厚度这一步（R2-4 的标注成本），同时回应 R1-2"固定宽度条带"：在数据集 2 上固定宽度不损失性能。
3. **跨度是最敏感的参数**：±25% 都掉 −0.047（≥ 9/10 seeds 变差）。仍赢 baseline +0.065，但对 box-mask 最好的后处理不再显著。×0.75 让预测 band 只画到中心线的 39%，fit 出的框变短；×1.25 时按验证集选参选中了 blend，固定 R18 参数只掉 −0.019，所以 ×1.25 的损失一半来自选参。论文里要写清楚：跨度要标到翼尖可见处（HBAT 已在触底时自动截短，左右截断按实际可见范围标）。
4. **在实测的标注误差水平上结论不变**：顶点 2 px、slope ±10%、重复标注差值 ×1，band + fit 掉 −0.008 到 −0.012，都不显著；对 baseline 仍 +0.100 到 +0.104（10/0），对 box-mask 最好的后处理仍 +0.031 到 +0.035（8/2）。尽管重复标注 ×1 的训练掩码和原始掩码只有 0.58 的 IoU，网络学到的是多个目标的平均形状，单个目标的标注误差影响很小。
5. **误差翻倍（顶点 5 px、slope ±20%、重复标注 ×2）掉 −0.022 到 −0.040**，对 baseline 仍 +0.072 到 +0.090（≥ 9/10），但对 box-mask 最好的后处理不再显著。性能随误差平滑下降，没有断崖。
6. **fusion 在所有档位都是 0.49–0.52**，和标准档同量级，扰动不改变"fusion 不是卖点"的结论。
7. **所有 15 个档位 band + fit 都赢 baseline**（最差的厚度 ×0.25 也是 +0.049，10/0）。"band + fit 对 baseline 有提升"对标注参数是稳健的；"对 box-mask 有额外优势"需要厚度在 ×0.5–×1.25 之内、跨度标准确、误差在实测水平。

## 局限

- 误差量级来自同一标注员、旧版工具的重复标注；68 对中 slope 41 对、厚度 45 对两次完全相同（滑块默认值），所以 slope 和厚度的实测误差偏小。两位标注员之间的差异要等第二位标注员（R2-4）再测；第 2 档的 ×2 可以当作更大误差的参考。
- 只在数据集 2、conv attention 头上做；检测框没有跟着扰动（只测监督掩码的敏感性）。

## 对论文

R2-4、R1-4 的敏感性部分可以直接用结果 1 的表或一张曲线图（横轴档位，纵轴 band + fit F1，画出 baseline 和 box-mask 最好的后处理两条参考线）。要点：厚度 ×0.5–×1.25 和统一厚度不影响结论；跨度最敏感，要准确标到可见翼尖；在实测的重复标注误差下提升不变。

## 复现

训练、重推理、后处理都用实验 1 的脚本（`run_seeds.py` 的 `hbatbox_flipfix_abs_ann_*`、`infer_bandbox.py` 的 `*_ann_*` 变体），配对聚合用实验 1 的 `aggregate_cv.py`。

```bash
python make_annot_masks.py                       # 15 套掩码 → ../shared/datasets/ds2_f*_s100_hbatbox/masks_ann_<档位>/，统计和叠加图 → results/
cd ../exp1_basic
L="t025 t050 t075 t125 t150 t200 tuni sp075 sp125 ap2 ap5 sl10 sl20 rep1 rep2"
python run_seeds.py --exps $(for l in $L; do printf 'hbatbox_flipfix_abs_ann_%s ' $l; done) --jobs 10 --workers 1
python infer_bandbox.py infer --exps $(for l in $L; do printf 'hbatbox_flipfix_abs_ann_%s ' $l; done)
python infer_bandbox.py prefit --variants $(for l in $L; do printf 'hbatbox_flipfix_abs_ann_%s_fitbox ' $l; done)
for l in $L; do e=hbatbox_flipfix_abs_ann_$l; python infer_bandbox.py build --variants ${e}_fitbox ${e}_bandbox_nms ${e}_r18_fitbox & done; wait
python aggregate_cv.py
cd ../exp2_annotation_sensitivity && python r21_annot_sensitivity.py   # → results/summary.md、summary.json
```

两台 5090 各开 10 个进程，训练约 45–60 分钟（2026-11-22 实测：IWAC2 7 档 45 分钟，IWAC1 8 档 51 分钟），重推理 + 预拟合 + 选参约 25 分钟。
